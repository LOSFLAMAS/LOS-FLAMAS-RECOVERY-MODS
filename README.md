Recupera un mod de **Arma Reforger** a partir de la versión que se descarga del Workshop:

- **Proyecto para Workbench** con sus `.meta` y GUIDs originales, listo para abrir y publicar como actualización.
- **Texturas** `.edds` convertidas a PNG.
- **Modelos** `.xob` convertidos a FBX, con LODs, huesos, pesos, materiales y colisiones.
- **Convertir** archivos sueltos (`.xob` → FBX, `.edds` → PNG) sin recuperar un mod completo.

**Se actualiza sola**: cada vez que la abres revisa si hay una versión nueva y, si la hay, la baja, se instala y se vuelve a abrir.

## Cómo instalarla

1. Haz clic en el botón **DESCARGAR** de arriba (siempre baja la versión más reciente).
2. Abre `FlamasModRecoverySetup.exe` y sigue el asistente. No pide permisos de administrador.
3. Ábrela desde el acceso directo del escritorio o del menú Inicio.

Si Windows muestra "Windows protegió tu PC", haz clic en **Más información → Ejecutar de todas formas**.

Tus mods recuperados se guardan en `Documentos\Flamas Mod Recovery\Recuperados`.
Para desinstalarla: Configuración → Aplicaciones → Flamas Mod Recovery.

## Novedades de la 2.2.0

Ahora pide iniciar sesion con tu cuenta de flamasengine.com y una llave de acceso. Las llaves se compran en la pagina. El programa viene protegido.
